# Agua

Sistema de gestión para una empresa de instalación, reparación y mantenimiento de bombas de agua (cliente: Miguel). Construido sobre **Laravel**.

El proyecto se compone de:

- **Zona pública:** web corporativa + catálogo + contacto + SEO.
- **Panel privado (ERP/CRM):** clientes, presupuestos, facturación (VeriFactu), gastos, trabajos, almacén, estadísticas y administración.
